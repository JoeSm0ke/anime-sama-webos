# Configuration reseau

L'application conserve les preferences et la reprise sur la TV. La synchronisation avec un PC est facultative et exige un appairage local.

Le paquet ne doit pas contenir d'adresse IP personnelle, de token ou de compte. Une erreur reseau ne doit pas bloquer la navigation.

Les donnees de catalogue et de lecture passent par une interface fournisseur documentee. Les sources publiees doivent etre autorisees. Un domaine contacte directement par l'app reste observable sur le reseau, meme si son nom n'est pas affiche.
