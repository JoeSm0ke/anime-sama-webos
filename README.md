# Anime Sama — webOS

Une interface TV conçue pour les anciennes versions de webOS.

## Le projet

Navigation à la télécommande, recherche, fiches de séries et reprise de lecture : cette édition vise les téléviseurs LG dont le navigateur intégré impose encore certaines limitations.

L'historique est conservé localement. La synchronisation avec un PC restera une option à configurer, pas un prérequis.

## Matériel

LG webOS

## Installation

Installation prévue avec un paquet IPK autonome et une notice adaptée au téléviseur.

## État

Pas encore de paquet public. Le code réseau, la compatibilité et les conditions d'utilisation des sources sont en cours de vérification.

Le dépôt sert pour l'instant à documenter le projet. Il ne contient pas encore de version à installer. Les premiers fichiers de code seront ajoutés après la vérification des informations privées et des droits de redistribution.
